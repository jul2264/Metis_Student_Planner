# Metis Desktop 🎓

Metis is a desktop utility for students, built entirely in Java with the JavaFX framework. It helps you manage your courses, track your grades, and calculate your Semester (SGPA) and Cumulative (CGPA) GPA.

## ✨ Features

* **GPA Calculation:** Easily calculate your SGPA and CGPA.
* **Course Management:** Add, edit, or remove courses and their corresponding grades and credits.
* **Simple Interface:** A clean and user-friendly GUI built with JavaFX.

## 🛠️ Tech Stack

* **Core:** Java
* **GUI:** JavaFX
* **Build:** Apache Maven

## 🚀 How to Run

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/gayathrisathish/metis-desktop.git](https://github.com/gayathrisathish/metis-desktop.git)
    cd metis-desktop-main
    ```

2.  **Build the project using Maven:**
    ```bash
    mvn clean package
    ```

3.  **Run the application:**
    ```bash
    mvn javafx:run
    ```
